# GeoStamp

Cap waktu, koordinat, alamat, dan peta pada foto, dibuat dari template OpenCamera. Berjalan sepenuhnya di browser (tanpa server, foto tidak diunggah).

## Fitur
- Seret foto (banyak sekaligus), pratinjau langsung, unduh satu atau semua
- Konverter koordinat: ketik desimal atau DMS, hasil DMS otomatis
- Preset lokasi (disimpan di browser)
- Peta: screenshot dengan crop geser + zoom, atau OpenStreetMap otomatis
- Isi alamat dari koordinat (Nominatim), zona WIB/WITA/WIT, tambah menit per foto

## Catatan
- Peta OSM dan alamat otomatis butuh internet; atribusi © OpenStreetMap ikut tercetak di peta.
- Data EXIF asli tidak ikut ke hasil ekspor.
